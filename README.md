# Робот-автомобіль з віддаленим керуванням (ESP32-S3-CAM)

Курсова робота: «Конструювання робота-автомобіля з віддаленим керуванням».
Автор: [Калюх Станіслав Володимирович Феі-21]

## Опис

Двоколісна платформа з камерою, яка керується з телефона по Wi-Fi.
Плата ESP32-S3-CAM створює точку доступу, передає відео з камери та приймає команди руху.

## Склад

| Вузол | Компонент |
|---|---|
| Контролер | ESP32-S3-CAM HW-679 (N16R8: 16 МБ Flash, 8 МБ PSRAM) |
| Камера | OV2640, шлейф у роз'ємі FPC на платі |
| Драйвер моторів | TB6612FNG (модуль) |
| Шасі | Робо-платформа Мини 2-х палубна (2 ведучих колеса) |
| Живлення | 2× Li-ion 18650 EVE 2850 мАг (2S, 7,4 В) + BMS 2S 20 А |
| Перетворювачі | 2× Mini560 PRO, фіксований вихід 5 В |
| Прошивка | USB-UART адаптер 3,3 В |

## Живлення

- Акумулятори → BMS → запобіжник → вимикач → шина VBAT.
- Mini560 №1 (+5V_LOGIC) живить плату ESP32-S3-CAM.
- Mini560 №2 (+5V_MOT) живить драйвер моторів (VM). Мотори розраховані на 3-4,5 В, тому швидкість обмежується ШІМ у програмі.
- Живлення моторів і логіки розділене, щоб піки струму моторів не перезавантажували плату.

## Розпіновка

| Пін плати | Функція |
|---|---|
| IO41 | AIN1 (мотор A) |
| IO40 | AIN2 (мотор A) |
| IO39 | BIN1 (мотор B) |
| IO38 | BIN2 (мотор B) |
| IO43 / IO44 | UART0 (TX / RX) для прошивки |
| IO0 | BOOT (джампер на землю при прошивці) |
| RST | кнопка скидання |

Піни PWMA, PWMB і STBY драйвера підтягнуті до +3V3, швидкість задається ШІМ на входах AIN/BIN.

## Структура репозиторію

- `*.kicad_sch`, `*.kicad_pro` — принципова схема в KiCad
- `docs/` — PDF схеми, список деталей (план)
- `firmware/` — прошивка ESP32-S3 (план)
- `app/` — застосунок для телефона: відео та керування (план)

## Прошивка

Підключи USB-UART адаптер (рівні 3,3 В): TX адаптера до IO44, RX до IO43, GND до GND. Для входу в режим прошивки замкни джампер IO0-GND і натисни RST. Плату під час прошивки живи окремо від адаптера.
